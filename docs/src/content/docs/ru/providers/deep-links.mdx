Koala Clash регистрируется в системе как обработчик ссылок `koala-clash://`. Кнопка с такой ссылкой в
личном кабинете открывает приложение и добавляет подписку — пользователю не нужно ничего копировать.

## Формат

```text
koala-clash://install-config?url=<ссылка на подписку>&name=<название>
```

| Параметр | Обязателен | Что это |
| --- | --- | --- |
| `url` | да | Ссылка на подписку, закодированная через `encodeURIComponent`. |
| `name` | нет | Название профиля в окне подтверждения. |

Приложение также принимает схемы `clash://` и `mihomo://` с тем же форматом. Их могут перехватывать
другие клиенты, поэтому для кнопки «Добавить в Koala Clash» используйте `koala-clash://`.

## Пример

```html
<a href="koala-clash://install-config?url=https%3A%2F%2Fexample.com%2Fsub%2Ftoken&name=My%20VPN">
  Добавить в Koala Clash
</a>
```

Собрать ссылку в JavaScript:

```js
const link =
	'koala-clash://install-config?url=' +
	encodeURIComponent(subscriptionUrl) +
	'&name=' +
	encodeURIComponent('My VPN');
```

## Что происходит после нажатия

<Steps>

1. Система открывает Koala Clash или переключается на уже запущенный.

2. Приложение показывает окно **«Импортировать конфигурацию подписки?»** с названием и ссылкой. Если
   `name` не передан, приложение отправляет на ссылку `HEAD`-запрос и берёт название из
   [`profile-title`](../headers/) или `content-disposition`.

3. После подтверждения приложение скачивает подписку обычным запросом — с
   [заголовками устройства](../headers/#что-отправляет-приложение) — и добавляет профиль. Новый
   профиль сразу становится активным.

</Steps>

## Ошибки

| Ситуация | Что увидит пользователь |
| --- | --- |
| В ссылке нет `url` | «Отсутствует параметр: url» |
| Подписка с этим `url` уже добавлена | «Эта подписка уже существует» |
| Панель ответила заголовком лимита устройств | Окно «Лимит устройств превышен» с кнопкой на `support-url` |
| Панель вернула не конфиг Mihomo | «Неверный формат подписки…» |

<Aside type="tip">
  Если кнопка не открывает приложение, значит, Koala Clash не установлен или система не знает об
  обработчике ссылок. Держите рядом кнопку «Скопировать ссылку» — подписку можно
  [добавить вручную](../../usage/subscriptions/).
</Aside>
