При добавлении и обновлении подписки Koala Clash делает `GET`-запрос по ссылке. В запросе он сообщает
панели данные об устройстве, а из ответа, кроме самого конфига, читает служебные заголовки: название
профиля, трафик, срок действия, объявление, ссылки на поддержку и оплату.

## Что отправляет приложение

| Заголовок | Значение |
| --- | --- |
| `User-Agent` | `koala-clash/<версия>`, например `koala-clash/1.4.1`. Пользователь может задать свой в настройках профиля. |
| `x-hwid` | Идентификатор устройства: 16 hex-символов, SHA-256 от machine ID системы. |
| `x-device-os` | `Windows`, `macOS` или `Linux`. |
| `x-ver-os` | Версия ОС, например `24H2`, `15.3` или `Ubuntu 24.04`. |
| `x-device-model` | Модель устройства, например `Mac14,2 (M2)`. |

<Aside>
  Панель должна отдавать для этого `User-Agent` конфиг Mihomo (Clash Meta) в YAML. Ответ с
  `Content-Type: text/html` или `text/xml` приложение отклоняет как ошибку формата.
</Aside>

## Что приложение читает из ответа

Имена заголовков не зависят от регистра. Приложение читает их только из успешного ответа (`2xx`).

| Заголовок | Что делает |
| --- | --- |
| `profile-title` | Название профиля. |
| `content-disposition` | Запасной источник названия (`filename=`), если нет `profile-title`. |
| `subscription-userinfo` | Трафик и срок: `upload=…; download=…; total=…; expire=…` — байты и Unix-время в секундах. `total=0` показывается как безлимит, без `expire` срок бессрочный. |
| `profile-update-interval` | Интервал автообновления в **часах**. Пользователь не может его изменить: поле блокируется с подсказкой «интервал задаётся удалённо». |
| `profile-logo` | URL картинки. Логотип показывается рядом с названием профиля на главной и в списке профилей. |
| `announce` | Объявление под названием профиля на главной. `\n` — перенос строки. |
| `support-url` | Ссылка «Поддержка» внизу главной и в меню профиля. Для `t.me` и `tg:` рисуется иконка Telegram. |
| `profile-web-page-url` | Пункт «Главная страница» в меню профиля. |
| `profile-web-page-name` | Подпись кнопки продления (вместе с `profile-web-page-url`). |
| `global-mode` | `false` скрывает глобальный режим в приложении и трее и переключает профиль в режим правил. |
| `expand-proxy-groups` | `true` / `false` — включает или выключает настройку «Раскрывать группы по умолчанию». |
| `custom-css` | URL CSS-темы. Тема скачивается и применяется, пока профиль активен. Шаблон — на странице [Темы](../../usage/themes/). |
| `x-hwid-limit`, `x-hwid-max-devices-reached` | Значение `true` — лимит устройств: подписка не добавляется и не обновляется, приложение показывает окно «Лимит устройств превышен» с кнопкой на `support-url`. |

Значения `profile-title`, `profile-web-page-name` и `announce` можно передать в Base64 с префиксом
`base64:` — так удобно отдавать кириллицу и эмодзи.

## Кнопка продления

Когда до конца подписки остаётся 3 дня или меньше, на главной вместо статистики появляется
предупреждение с кнопкой:

- если заданы `profile-web-page-url` и `profile-web-page-name` — кнопка с этой подписью ведёт на
  страницу из `profile-web-page-url`;
- иначе, если задан `support-url`, — кнопка «Оплатить» ведёт на него;
- если нет ни того, ни другого, кнопки не будет.

## Пример ответа

```http
HTTP/1.1 200 OK
Content-Type: text/yaml; charset=utf-8
profile-title: base64:0JzQvtC5IFZQTg==
subscription-userinfo: upload=1073741824; download=5368709120; total=107374182400; expire=1798761600
profile-update-interval: 12
profile-logo: https://example.com/logo.png
announce: base64:0J/RgNC+0YTQuNC70LDQutGC0LjQutCwINCyINC/0Y/RgtC90LjRhtGD
support-url: https://t.me/example_support
profile-web-page-url: https://example.com/account
profile-web-page-name: base64:0J/RgNC+0LTQu9C40YLRjA==
global-mode: false
```

<Aside type="caution">
  Когда подписку импортируют [кнопкой с сайта](../deep-links/) (`koala-clash://install-config?url=…`), окно
  подтверждения запрашивает название обычным `HEAD`-запросом, без заголовков устройства. Если панель
  не отвечает на `HEAD`, передайте название в параметре `name` ссылки.
</Aside>
