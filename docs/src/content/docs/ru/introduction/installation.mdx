Все сборки публикуются в [релизах на GitHub](https://github.com/coolcoala/koala-clash/releases/latest).
Выберите файл под свою систему и архитектуру процессора.

<Tabs syncKey="os">
<TabItem label="Windows">

| Файл | Для чего |
| --- | --- |
| `Koala.Clash_x64-setup.exe` | Установщик для обычных ПК (Intel, AMD) |
| `Koala.Clash_arm64-setup.exe` | Установщик для ПК на ARM (Snapdragon) |
| `Koala.Clash_x64-portable.7z` | Портативная версия без установки |
| `Koala.Clash_arm64-portable.7z` | Портативная версия для ARM |

Портативную версию распакуйте в любую папку. Настройки и профили она хранит в папке `data` рядом с
программой — её удобно носить на флешке.

### Права администратора

При первом запуске приложение покажет окно **«Требуются права администратора»**. Режиму TUN нужно
один раз запуститься от имени администратора, чтобы зарегистрировать задачу в планировщике — после
этого права больше не запрашиваются.

- **Перезапустить от имени администратора** — рекомендуемый вариант, TUN будет работать.
- **Продолжить без прав администратора** — приложение будет работать только через системный прокси и
  больше не спросит. Выдать права можно позже в
  [настройках ядра](../../usage/settings/#настройки-ядра): **Статус задачи** → **Управление**.

</TabItem>
<TabItem label="macOS">

| Файл | Для чего |
| --- | --- |
| `Koala.Clash_arm64.pkg` | Mac на Apple Silicon (M1 и новее) |
| `Koala.Clash_x64.pkg` | Mac на Intel |

Откройте `.pkg` и пройдите шаги установщика.

Для режима TUN ядру нужны системные права. Если TUN не включается, откройте
[настройки ядра](../../usage/settings/#настройки-ядра) → **Статус авторизации** → **Управление** →
**Авторизовать ядро**. Система попросит пароль пользователя.

</TabItem>
<TabItem label="Linux">

**Arch Linux и производные** — пакет [`koala-clash-bin`](https://aur.archlinux.org/packages/koala-clash-bin) в AUR:

```sh
yay -S koala-clash-bin
```

Или скачайте пакет из релиза и установите его менеджером пакетов:

| Файл | Дистрибутив | Команда |
| --- | --- | --- |
| `Koala.Clash_amd64.deb`, `Koala.Clash_arm64.deb` | Debian, Ubuntu, Mint | `sudo apt install ./Koala.Clash_amd64.deb` |
| `Koala.Clash_x86_64.rpm`, `Koala.Clash_aarch64.rpm` | Fedora, openSUSE | `sudo dnf install ./Koala.Clash_x86_64.rpm` |
| `Koala.Clash_x64.pkg.tar.xz`, `Koala.Clash_aarch64.pkg.tar.xz` | Arch без AUR | `sudo pacman -U Koala.Clash_x64.pkg.tar.xz` |

Для режима TUN ядру нужны системные права: [настройки ядра](../../usage/settings/#настройки-ядра) →
**Статус авторизации** → **Управление** → **Авторизовать ядро**.

</TabItem>
</Tabs>

## Первый запуск

<Steps>

1. Запустите Koala Clash. Откроется короткое интерактивное обучение — его можно пропустить кнопкой
   **Пропустить** и открыть снова в настройках (**Открыть руководство**).

2. [Добавьте подписку](../../usage/subscriptions/) — ссылку даёт ваш провайдер.

3. Нажмите большую кнопку на главном экране — [подробнее о подключении](../../usage/connecting/).

</Steps>

## Обновления

Если в **Настройках** включена **Автоматическая проверка обновлений**, приложение само сообщит о новой
версии баннером с кнопкой **Обновить сейчас**. Проверить вручную можно там же: **Проверить обновления**.

<Aside type="tip">
  Держите приложение обновлённым: многие проблемы уже исправлены в свежих версиях.
</Aside>
