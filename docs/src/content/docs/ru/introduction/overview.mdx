Эта страница специально оставлена минимальной и служит шаблоном для будущих страниц документации в ветке `docs`.

![Превью Koala Clash](../../../../assets/preview.png)

## Что покрывает этот шаблон

- общее описание продукта
- будущие заметки по установке
- будущие гайды по профилям и маршрутизации
- будущую документацию по темам и интерфейсу

## Примечания

- Сайт документации находится в папке `docs/`.
- Текущая ветка сфокусирована только на документации.
- Новые страницы можно добавлять по этой же структуре без смены общего каркаса.
