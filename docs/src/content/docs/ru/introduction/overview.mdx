Koala Clash — десктопный клиент для ядра [Mihomo](https://github.com/MetaCubeX/mihomo) (Clash Meta)
под Windows, macOS и Linux. Добавляете подписку от своего провайдера, нажимаете одну кнопку — и трафик
идёт через прокси по правилам из подписки.

![Главный экран Koala Clash](../../../../assets/preview.png)

## Возможности

- **Подключение одной кнопкой** — через виртуальный сетевой интерфейс (TUN) или системный прокси.
- **Подписка на главном экране** — остаток трафика, дни до окончания, дата, объявления провайдера и
  ссылка на поддержку.
- **Импорт в один клик** — кнопкой на сайте провайдера, ссылкой из буфера обмена или файлом.
- **Свои правила маршрутизации** поверх подписки — они не пропадают при её обновлении.
- **Встроенные ядра Mihomo** — стабильное и предварительное.
- **Трей, плавающее окно и горячие клавиши** — переключение без открытия главного окна.
- **Темы**, в том числе тема, которую присылает провайдер вместе с подпиской.
- **Интерфейс** на русском, английском и китайском.

Koala Clash основан на [Sparkle](https://github.com/xishang0128/sparkle).
