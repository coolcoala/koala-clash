Тема — это CSS-файл, который Koala Clash подключает поверх стандартного оформления в главном и
плавающем окне. Одна тема может задать цвета сразу для светлого и тёмного режима.

## Как подключить тему

### От провайдера

Провайдер может прислать тему вместе с подпиской через заголовок
[`custom-css`](../../providers/headers/) — в нём ссылка на CSS-файл. Приложение скачивает файл и
включает тему, пока этот профиль активен. При каждом обновлении подписки файл скачивается заново,
так что правки на стороне провайдера доходят до пользователей сами. В списке тем она называется по имени
файла из ссылки.

### Вручную

Выбор темы — скрытая настройка. Нажмите 7 раз на **Версию приложения** внизу **Настроек**, после этого в
**Настройках внешнего вида** появится пункт **Тема**:

- **Импортировать тему** — добавить CSS-файл с диска;
- **Загрузить тему** — скачать готовые темы из общего каталога;
- **Редактировать тему** — открыть CSS выбранной темы во встроенном редакторе;
- **По умолчанию** в списке — вернуть стандартное оформление.

Название темы в списке берётся из первой строки файла, если это комментарий вида `/* Моя тема */`.
Иначе показывается имя файла.

<Aside type="caution">
  Тема привязана к профилю. При переключении профиля и при каждом обновлении активного профиля,
  включая автообновление, приложение ставит тему профиля из `custom-css` или **По умолчанию**. Тема,
  выбранная вручную, держится только до следующего обновления.
</Aside>

## Как сделать свою тему

<Steps>

1. Скачайте шаблон и поменяйте цвета в первых двух блоках: `html:not(.dark)` — светлая тема,
   `html.dark` — тёмная. Правила ниже обычно трогать не нужно: они берут цвета из этих переменных.

2. Если вместо карты на фоне нужна своя картинка, укажите её в `--koala-custom-background`, например
   `url('https://example.com/bg.jpg') center / cover`. Блок 4 шаблона скрывает карту — удалите его,
   если карта нужна.

3. Добавьте первой строкой название: `/* Моя тема */`.

4. Импортируйте файл в приложении и проверьте обе темы: **Цвет фона** → **Светлая** и **Тёмная**.
   Посмотрите главный экран, группы прокси, настройки и диалоги.

5. Чтобы раздавать тему пользователям, выложите файл по постоянной ссылке и передавайте её в заголовке
   `custom-css`.

</Steps>

## Основные переменные

| Переменная | Что красит |
| --- | --- |
| `--card` | Фон карточек, полей выбора и всплывающих панелей. |
| `--border` | Рамки карточек и полей, выключенные переключатели. |
| `--foreground`, `--muted-foreground` | Основной и второстепенный текст. |
| `--primary` | Акцент: отмеченные чекбоксы, включённые переключатели. |
| `--success` | Хорошая задержка, выбранный сервер. |
| `--stroke-power-on`, `--gradient-start-power-on`, `--gradient-end-power-on` | Кнопка подключения во включённом состоянии. |
| `--stroke-power-off`, `--gradient-start-power-off`, `--gradient-end-power-off` | Кнопка подключения в выключенном состоянии. |
| `--koala-custom-background` | Фон окна. |
| `--koala-custom-card-shadow` | Тень карточек. |
| `--koala-custom-selected-background` | Фон карточки выбранного сервера. |

<Aside>
  Правила шаблона находят элементы по классам интерфейса. Если в новой версии приложения разметка
  изменится, часть правил может перестать срабатывать — проверяйте тему после обновлений.
</Aside>
