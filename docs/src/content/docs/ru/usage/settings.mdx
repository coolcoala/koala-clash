**Настройки** открываются из нижней части бокового меню. Ниже — разделы по порядку. Для обычной работы
большинство параметров менять не нужно.

<Aside>
  Некоторые пункты скрыты, чтобы их не меняли случайно: **Отключить ускорение GPU**, **Тема**,
  **Очистить кэш**. Чтобы их показать, нажмите 7 раз на **Версию приложения** внизу настроек.
</Aside>

## Режимы подключения

| Настройка | Что делает |
| --- | --- |
| **Основной переключатель** | Что включает кнопка на главном экране: **Режим TUN** или **Режим прокси**. Подробнее — в [Подключении](../connecting/#кнопка-подключения). |
| **Режим TUN** | Открывает **Настройки TUN**: стек, перехват DNS, исключённые сети и другие параметры виртуального интерфейса. |
| **Режим прокси** | Открывает **Настройки системного прокси**: режим **Вручную** или **PAC**, **Список исключений прокси** — адреса, которые идут мимо прокси. |

## Общие

| Настройка | Что делает |
| --- | --- |
| **Автозапуск** | Запускать приложение вместе с системой. |
| **Тихий запуск** | Запускаться свёрнутым в трей, без главного окна. |
| **Автоматическая проверка обновлений** | Сообщать о новых версиях. |
| **Отключить ускорение GPU** (скрыто) | Может помочь, если окно мерцает или приложение падает. Требует перезапуска. |

Ниже — **Язык** интерфейса: русский, английский или китайский.

## Внешний вид

| Настройка | Что делает |
| --- | --- |
| **Показать плавающее окно** | Маленький индикатор поверх других окон. Если приложение падает, включите **Отключить ускорение GPU**. |
| **Вращать иконку плавающего окна…** | Иконка крутится быстрее при большей скорости сети. |
| **Скрыть иконку в трее** | Убрать иконку из трея. |
| **Показать информацию об узле в меню трея** | Текущий сервер в меню трея. Кроме Linux. |
| **Показать иконку в Dock** | Только macOS. |
| **Поверх всех окон** | Главное окно всегда сверху. |
| **Использовать системную строку заголовка** | Системная рамка окна вместо встроенной. |
| **Цвет фона** | **Авто**, **Тёмная** или **Светлая** тема. |
| **Тема** (скрыто) | Оформление приложения, см. ниже. |

### Темы

- **Загрузить тему** скачивает готовые темы из общего каталога.
- **Импортировать тему** добавляет CSS-файл темы с диска.
- **Редактировать тему** открывает CSS выбранной темы в редакторе.

Провайдер может прислать свою тему вместе с подпиской через [заголовок `custom-css`](../../providers/headers/).
Как устроены темы и шаблон для своей темы — на странице [Темы](../themes/).

## Дополнительные настройки

| Настройка | Что делает |
| --- | --- |
| **Автоматически переходить в облегчённый режим** | Через заданное время после закрытия окна выгружать интерфейс, чтобы экономить память. **Поведение облегчённого режима**: оставить только ядро или закрыть только интерфейс. |
| **Управлять настройками DNS**, **Управлять настройками определения доменов** | Применять настройки DNS и sniffing из приложения поверх подписки. Если выключено, используются настройки из подписки. |
| **Отдельный рабочий каталог для каждого профиля** | Убирает конфликты, если в разных профилях группы называются одинаково. |
| **Горячая перезагрузка конфигурации при смене профиля** | Применять профиль без перезапуска ядра. |
| **Останавливать ядро при потере сети** | Останавливать ядро без сети и запускать снова, когда сеть вернётся. |
| **Включать прямой режим для указанных Wi-Fi SSID** | В перечисленных Wi-Fi сетях, например дома, трафик идёт напрямую. |
| **Приоритет процесса ядра** | Только Windows. Приоритет процесса ядра в системе. |

## Горячие клавиши

В **Настройках горячих клавиш** можно назначить глобальные сочетания: показать окно или плавающее
окно, включить **Режим прокси** или **Режим TUN**, переключить режим правил, глобальный или прямой
режим, перезапустить приложение и выйти, сохранив ядро. Нажмите на поле и введите сочетание.

## Действия

| Действие | Что делает |
| --- | --- |
| **Открыть руководство** | Заново показать интерактивное обучение. |
| **Проверить обновления** | Проверить новую версию вручную. |
| **Сбросить приложение** | Удалить все настройки и профили. Действие необратимо. |
| **Очистить кэш** (скрыто) | Очистить кэш интерфейса. |
| **Выйти, сохранив ядро** | Закрыть приложение, оставив ядро работать в фоне. |
| **Выйти из приложения** | Полностью выйти. |

Внизу показаны **Версия Mihomo** и **Версия приложения**. Кнопка с шестерёнкой рядом с версией Mihomo
открывает настройки ядра.

## Настройки ядра

| Настройка | Что делает |
| --- | --- |
| **Версия ядра** | **Встроенное стабильное**, **Встроенное предварительное** или **Использовать системное ядро**. Кнопка **Обновить ядро** обновляет выбранное. |
| **Режим работы** | Как ядро получает права для TUN: **Планировщик задач** на Windows или **Запуск с повышенными правами** на macOS и Linux, либо **Системная служба**. |
| **Статус задачи**, **Статус авторизации** | Выданы ли права. **Управление** позволяет выдать или отозвать их. |
| **Уровень логирования** | Подробность [логов](../connections-logs/#логи). |
| **Дни хранения логов** | Сколько дней хранить файлы логов. |
| **Настройки портов** | **Смешанный порт** (по умолчанию `7897`) — HTTP- и SOCKS-прокси для программ, которые настраиваются вручную. **Разрешить подключения из локальной сети** даёт пользоваться прокси другим устройствам в сети. |
| **Настройки контроллера** | Внешний API ядра и веб-панель. |

<Aside type="caution">
  Меняйте параметры ядра, только если понимаете, что делаете: неверные значения могут помешать ядру
  запуститься. Вернуть всё как было можно через **Сбросить приложение**.
</Aside>
