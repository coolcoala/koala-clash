## Подключения

Вкладка **Подключения** показывает все соединения, которые прошли через ядро: куда, через какое
правило и через какой сервер они пошли. Это главный инструмент, когда один сайт или программа
работает не так, как нужно.

- **Активные** и **Закрытые** — вкладки с текущими и уже завершёнными соединениями.
- **По процессам** (по умолчанию) группирует соединения по программам, **Классический вид**
  показывает общий список. Режим меняется в **Настройках подключения** — кнопка с шестерёнкой в шапке.
- **Фильтр** ищет по хосту, процессу и другим полям.
- **Пауза** замораживает список, **Продолжить** снова обновляет его.
- **Закрыть все подключения** обрывает текущие соединения — полезно после смены сервера.

Нажмите на соединение, чтобы открыть **Детали подключения**. Самое полезное там:

| Поле | Что показывает |
| --- | --- |
| **Хост**, **Обнаруженный хост** | Домен, к которому шло соединение. |
| **Правило** | Какое правило сработало. |
| **Цепочка прокси** | Через какую группу и сервер ушёл трафик, или `DIRECT`. |
| **Имя процесса** | Какая программа открыла соединение. |

### Сайт или программа идёт не туда

<Steps>

1. Откройте **Подключения** и введите в **Фильтр** адрес сайта или имя программы.

2. Откройте сайт или запустите программу.

3. Посмотрите **Цепочку прокси** у её соединений: `DIRECT` значит, что трафик идёт в обход прокси.

4. Добавьте [своё правило](../rules/) для этого домена или процесса.

</Steps>

Сайты загружают картинки и видео с других доменов. Если сайт открывается частично, посмотрите все
его соединения и добавьте правила для тех, что идут через `DIRECT`.

## Логи

Вкладка **Логи** показывает сообщения ядра в реальном времени: ошибки подключения к серверам, проблемы
с DNS, предупреждения конфигурации.

- **Фильтр** ищет по тексту сообщений.
- Кнопка автопрокрутки в шапке: когда она выключена, поток логов ставится на паузу, и строки не
  убегают, пока вы их читаете.
- **Очистить логи** очищает список.

Подробность логов задаётся в [настройках ядра](../settings/#настройки-ядра) → **Уровень логирования**.
Для диагностики выберите `info` или `debug`, в обычной работе хватает `warning`.

<Aside type="tip" title="Отправить логи в поддержку">
  Логи также пишутся в файлы. Откройте их через трей: **Открыть папку** → **Папка логов** — и
  приложите нужный файл к обращению.
</Aside>
