Серверы подписки собраны в **группы прокси**. Их набор и названия задаёт провайдер: обычно есть
основная группа с выбором страны и отдельные группы для отдельных сервисов.

## Как сменить сервер

<Steps>

1. Откройте **Группы прокси** в боковом меню или нажмите на текущий сервер на главном экране.

2. Нажмите на группу, чтобы раскрыть список серверов.

3. Нажмите **Тест задержки** у группы и выберите сервер с меньшей задержкой.

</Steps>

Выбор сохраняется между запусками. Кнопка **Найти текущий узел** прокручивает список к выбранному
серверу.

### Типы групп

У каждой группы есть значок типа:

- **Ручной выбор** (значок курсора) — сервер выбираете вы.
- **Автоматические** (значок молнии) — группа сама переключается на сервер с наименьшей задержкой.
  Выбирать в ней вручную обычно не нужно.

## Тест задержки

Задержка показывается в миллисекундах: чем меньше, тем лучше. **Тайм-аут** значит, что сервер не
ответил за отведённое время — выберите другой.

Задержка — это время ответа сервера, а не скорость загрузки. Если сервер с хорошей задержкой работает
медленно, попробуйте соседний.

## Настройки группы прокси

Кнопка с шестерёнкой в шапке страницы:

| Настройка | Что делает |
| --- | --- |
| **Количество столбцов узлов прокси** | Сколько серверов в ряду. |
| **Метод сортировки узлов** | По умолчанию, по задержке или по имени. |
| **Подробности группы прокси**, **Подробности узла прокси** | Сколько информации показывать на карточках. |
| **Отключаться при смене узла** | Закрывать текущие соединения при смене сервера, чтобы они сразу пошли через новый. |
| **Раскрывать группы по умолчанию** | Открывать страницу с раскрытыми группами. |
| **URL для теста задержки** | Адрес, по которому меряется задержка. По умолчанию `https://www.gstatic.com/generate_204`. |
| **Количество параллельных тестов задержки** | Сколько серверов проверять одновременно. По умолчанию 50. |
| **Тайм-аут теста задержки** | Сколько ждать ответа, в миллисекундах. По умолчанию 5000. |

<Aside type="tip" title="Сервер сам переключается обратно">
  Скорее всего, мешает другая программа, которая тоже перехватывает трафик: второй VPN, встроенный
  прокси Telegram, Zapret. Отключите её и перезапустите Koala Clash.
</Aside>
