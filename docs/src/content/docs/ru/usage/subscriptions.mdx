Подписка — это ссылка от вашего провайдера, по которой приложение скачивает конфигурацию: список
серверов, группы и правила. В Koala Clash каждая подписка становится **профилем**.

<Aside type="caution">
  Ссылка на подписку — ваш личный ключ доступа. Не публикуйте её и не отправляйте посторонним: каждое
  устройство с этой ссылкой может занимать место в лимите устройств.
</Aside>

## Как добавить

<Tabs>
<TabItem label="Кнопкой на сайте">

Если у провайдера в личном кабинете есть кнопка «Добавить в Koala Clash», нажмите её. Приложение
откроется и покажет окно **«Импортировать конфигурацию подписки?»** с названием и ссылкой. Проверьте,
что ссылка ведёт на ваш сервис, и подтвердите импорт.

</TabItem>
<TabItem label="Ссылкой">

<Steps>

1. Скопируйте ссылку на подписку в личном кабинете провайдера.

2. Откройте **Профили** в боковом меню и нажмите **+** в шапке. Если профилей ещё нет, на главном
   экране будет кнопка **Добавить профиль**.

3. Нажмите **Вставить из буфера обмена** или вставьте ссылку в поле вручную.

4. Нажмите **Сохранить**. Приложение скачает подписку и сделает её активной.

</Steps>

</TabItem>
<TabItem label="Файлом">

Если у вас есть готовый конфиг Mihomo (`.yaml`), перетащите его на страницу **Профили** или выберите
в форме добавления **Тип профиля** → **Локальный** → **Выбрать файл**. **Создать пустой** даёт
профиль, который можно заполнить вручную.

Локальный профиль не обновляется из сети.

</TabItem>
</Tabs>

### Дополнительные настройки

В форме добавления есть блок **Дополнительные настройки**. Обычно его не нужно трогать.

| Настройка | Что делает |
| --- | --- |
| **Пользовательский UA** | Свой `User-Agent` для запроса подписки. По умолчанию — `koala-clash/<версия>`. |
| **Проверять формат подписки** | Отклоняет ответ, если это не конфиг Mihomo. |
| **Обновлять через прокси** | Скачивать подписку через уже запущенное ядро. |
| **Автообновление** | Обновлять подписку автоматически. |
| **Интервал обновления (минуты)** | Как часто обновлять. Если интервал задаёт провайдер, поле заблокировано. |

## Обновление подписки

Список серверов, правила, остаток трафика и срок действия приходят только при обновлении. Обновляйте
подписку после оплаты или смены тарифа и всегда, когда что-то перестало работать.

- **Главный экран** — кнопка обновления рядом с названием профиля.
- **Профили** — кнопка обновления на карточке профиля или **Обновить все профили** в шапке.

С включённым автообновлением приложение делает это само по интервалу.

<Aside type="tip">
  Если обновление не помогает, удалите профиль и добавьте подписку заново.
</Aside>

## Несколько профилей

Активный профиль выделен на странице **Профили**. Чтобы переключиться, нажмите на карточку другого
профиля. Переключаться можно и из трея: пункт **Профили**.

У каждой карточки есть меню **⋮**:

| Пункт | Что делает |
| --- | --- |
| **Главная страница**, **Поддержка** | Ссылки от провайдера, если он их передал. |
| **Редактировать информацию** | Название, ссылка и [дополнительные настройки](#дополнительные-настройки). |
| **Редактировать файл** | Конфиг профиля. Правки перезапишутся при следующем обновлении подписки. |
| **Редактировать правила** | [Свои правила](../rules/) поверх подписки — они сохраняются при обновлении. |
| **Открыть файл** | Открыть конфиг во внешнем редакторе. |
| **Удалить** | Удалить профиль. |

## Если подписка не добавляется

**«Лимит устройств превышен».** Подписка уже используется на максимальном числе устройств. Отвяжите
лишнее устройство в личном кабинете провайдера или напишите в поддержку — кнопка есть прямо в окне
ошибки. Подписка в этом случае не добавляется и не обновляется.

**«Неверный формат подписки».** По ссылке пришёл не конфиг, а, например, веб-страница. Проверьте, что
скопировали именно ссылку на подписку, а не на личный кабинет.

**«Эта подписка уже существует».** Подписка с этой ссылкой уже добавлена — обновите существующий профиль.

**«Сетевое соединение сброшено…» или ошибка сертификата.** Проверьте интернет. Если провайдер заблокирован, включите
**Обновлять через прокси** в настройках профиля.

Подробнее о других проблемах — в разделе [Частые вопросы](../../help/faq/).
