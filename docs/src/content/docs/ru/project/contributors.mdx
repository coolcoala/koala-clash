## Стать одним из нас

<CardGrid>
	<Card title="Сообщить об ошибке" icon="warning">
		Нашли баг или не хватает функции — откройте
		[issue на GitHub](https://github.com/coolcoala/koala-clash/issues). Приложите версию приложения,
		систему и [логи](../../usage/connections-logs/#логи).
	</Card>
	<Card title="Код" icon="github">
		Pull request'ы принимаются в [coolcoala/koala-clash](https://github.com/coolcoala/koala-clash).
		Как собрать приложение локально — в README репозитория.
	</Card>
	<Card title="Переводы" icon="translate">
		Строки интерфейса лежат в `src/renderer/src/locales`. Поправьте перевод или добавьте новый язык.
	</Card>
	<Card title="Документация" icon="pencil">

	</Card>
</CardGrid>
