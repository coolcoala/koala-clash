# Theme Template Guide

`template.css` в этой папке теперь оформлен как нейтральный стартовый шаблон для тем с собственным wallpaper.

## Как делать новую тему

1. Скопируй `template.css` в новый файл с названием темы.
2. В первую очередь меняй только верхний блок `:root`.
3. Начинай с `--koala-theme-background`, затем подстрой RGB-токены `--base-*`, `--surface-*`, `--accent-*`, `--highlight-*`, `--info-*`.
4. Если оттенков не хватает, сначала добавь новый helper-токен наверху файла, а не хардкодь цвет внизу по селекторам.

## Что значат группы токенов

- `--base-*`: самые темные фоны и затемнение.
- `--surface-*`: карточки, инпуты и стеклянные поверхности.
- `--accent-*`: бордеры, вторичные акценты и тени.
- `--highlight-*`: яркий текст, CTA и активные состояния.
- `--info-*`: вспомогательный контрастный акцент для графиков и деталей.

## Правила для правок

- Старайся не переписывать нижнюю часть файла без необходимости: большинство тем можно собрать, меняя только токены наверху.
- Держи хороший контраст между `--foreground`, `--background`, `--card` и `--primary`.
- Для hover, focus и active состояний сохраняй заметную разницу, иначе тема будет выглядеть "плоской".
- Если используешь яркую картинку, усиливай `--sidebar-scrim-*`, `--modal-scrim` и `--koala-theme-background-filter`, а не текстовые цвета.
- Если элемент требует одноразового цвета, вынеси его в helper-токены рядом с остальными переменными.

## Чеклист перед завершением

- Проверь, что основные карточки, сайдбар, диалоги и таблицы читаемы.
- Проверь, что активные кнопки и переключатели заметно отличаются от неактивных.
- По возможности оставляй сырые `rgb(...)` и `#...` только в верхнем блоке переменных.
